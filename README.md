# Regyana Bed & Breakfast Website

## Student Information

**Student Number:** ST10528245  
**Module:** Web Development (WEDE5020)

## About the Project

This project is a website created for Regyana Bed & Breakfast.
The purpose of the website is to provide visitors with information
about the organisation, its services, accommodation and contact details.

## Website Pages

The website contains the following pages:

- Home Page
- About Us
- Services
- Enquiry
- Contact Us

## Services

Regyana Bed & Breakfast offers:

- Accommodation
- Breakfast
- Outdoor swimming pool
- Free Wi-Fi
- 24-hour front desk
- Catering services
- Event decoration
- Party and baby shower décor

## Technologies Used

- HTML5
- GitHub
- Visual Studio Code

## Images and Resources

The website uses images for the logo, accommodation and event
decoration to make the website more attractive and informative.
